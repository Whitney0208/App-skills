# 心血管类慢性疾病 Skill：指标更新对照表

讨论稿，2026-09-30。本文件另存为更新对照版，保留[原中文汇报表](cardiovascular-diseases-table.md)。本表将 2026-09-23 的原汇报表及[原完整规划](cardiovascular-diseases.md)，与[更新后的指标范围](cardiovascular-indicators-updated.md)逐项对照，并加入[纵向管理及 App 接入要求](longitudinal-app-requirements.md)。原英文汇报表保留为[初版参考](cardiovascular-diseases-table-en.md)，尚未同步为本对照版。

“原来”指初版已经明确写出的内容；“更新后”列出补充或细化，原有字段继续保留。原来只概括为专科报告的疾病，本次展开具体字段，不代表新增了这些疾病。表中项目是 App 拟支持保存的资料，不是每名患者的统一检查清单，也不代表功能或临床判断规则已经实现。

## 目标与适用人群

| 问题 | 当前规划 |
| --- | --- |
| 服务谁 | 不以 AD 或其他疾病标签作为启动条件。成人患者可同时有 PD、癌症、代谢病或尚无慢病诊断；儿童与妊娠患者需另行核对适用规则。 |
| 做什么 | 有相关资料时评估心血管风险与随访缺项；临床确诊后进入对应疾病的长期管理。 |
| 状态如何区分 | 风险因素、尚待确认的异常检查、确诊疾病及既往急性事件分开记录。 |
| 首版拟完整支持 | 成人高血压、慢性冠心病、心力衰竭、房颤；下方字段扩展不自动扩大实施承诺。 |
| 扩展目录 | 外周动脉疾病、脑血管病、瓣膜病、其他心律失常、主动脉瘤、成人先天性心脏病、静脉血栓栓塞后管理、风湿性心脏病。先保存确诊、报告及既定计划，再逐病实现规则。 |
| 较少见或罕见病目录 | 肥厚型心肌病、致心律失常性心肌病、肺动脉高压、遗传性长 QT 综合征、Brugada 综合征、家族性胸主动脉瘤。首版保存与展示专科资料，不套用通用高血压或心衰规则；这些疾病并非都极罕见。 |
| 跨病种边界 | 高血压既是管理对象，也是其他心血管病的风险因素；心梗和卒中后的长期预防纳入随访，卒中后的神经功能管理需与神经疾病负责人分工。 |

## 18 类疾病的指标更新对照

本表概括字段变化。具体适用情境、临床来源及逐病证据缺口见[指标更新详文](cardiovascular-indicators-updated.md)。未再次列出的初版字段仍保留。

| 疾病 | 原来写了什么 | 更新后补充或细化了什么 |
| --- | --- | --- |
| 高血压 | 成对血压、时间、家庭或诊室来源、设备、测量情境、个人目标；关注重复测量和长期趋势。 | 将测量情境拆成体位、测量侧、袖带和静息情况；保存已有动态血压的日间、夜间和全天结果。补充初评血常规、电解质、肌酐/eGFR、血脂、血糖或 HbA1c、TSH、尿检、UACR 和心电图。一次家用读数仍不用于直接确诊或改药。 |
| 慢性冠心病 | 确诊依据、胸部不适及变化、心梗或支架/搭桥史、运动耐量、心电图、功能检查和冠脉影像。 | 将症状拆成时间、持续时长、活动或静息情境、频率、缓解方式和功能影响；将影像拆成血管、部位、狭窄程度、方法及日期。肌钙蛋白保留为特定急性评估资料，不设为稳定期常规趋势指标。 |
| 心力衰竭 | 分型、左室射血分数（LVEF）、连续体重、气促、水肿、疲劳和功能变化；已有 BNP/NT-proBNP、肾功能和电解质。 | 增加历次超声日期与方法、NYHA 分级及日期、心衰住院事件和已有六分钟步行结果；补全初评资料，明确铁蛋白和转铁蛋白饱和度（TSAT）。药物调整与复查时间关联，不凭体重变化单独推断液体潴留或改药。 |
| 房颤 | 心电或医疗记录确认、发作状态、心率、症状、卒中/TIA 史、医生评估的风险和抗凝处方；漏服、出血和肾功能。 | 增加确认来源、监测起止时间、发作时长、房颤负荷及分母；保存风险工具版本、输入和评估日期；补充新诊断时的血常规、代谢面板、甲状腺功能和经胸超声资料。INR 按实际用药使用；穿戴提示不自动升级为确诊。 |
| 外周动脉疾病 | 行走诱发的腿部症状、足部伤口、踝肱指数（ABI）及既定计划。 | ABI 区分左右侧、静息或运动后，并保留踝压与臂压；按指征保存趾肱指数（TBI）、趾压及灌注资料；增加行走距离、静息痛、伤口愈合、血管影像和血运重建记录。 |
| 脑血管疾病及卒中后管理 | 已确认事件类型、日期和出院后预防计划；与神经疾病组协调。 | 展开病因及确定程度、脑和头颈血管影像、房颤筛查和抗栓适应证；保存已有 NIHSS、mRS 的时点与评估者，以及吞咽、活动和日常功能。缺血性与出血性事件分别处理。 |
| 心脏瓣膜病 | 超声中的具体瓣膜、病变类型、严重程度和原始报告。 | 按瓣膜和狭窄/反流展开瓣口面积、流速、压差或反流定量结果；增加原生/人工瓣、心腔及心功能、手术日期和瓣膜类型。具体参数按病变选择，不凭单项压差自动分级。 |
| 其他心律失常与传导异常 | 作为扩展类别保存节律资料、关键报告和随访计划。 | 展开医生确认的具体类型、PR/QRS/QT/QTc、监测时长、发作次数及持续时间、室早负荷、停搏或传导阻滞；保存症状时间对应及起搏器/ICD 事件。各亚型仍需独立规则审核。 |
| 主动脉瘤 | 影像测得的部位、直径和随访间隔。 | 增加解剖分段、最大径、测量平面、方法与日期；仅在可比时计算增长率并展示依据。补充修复史、残余病变和支架术后报告；支架规格与瘤体直径分开。 |
| 成人先天性心脏病 | 保存确诊、关键报告及既定随访计划，未逐病型展开指标。 | 增加具体缺陷、原始解剖、修复史、残余病变和专科团队；按病型保存氧饱和度、心室及瓣膜功能、分流方向、Qp/Qs 和已有导管资料。区分修复前后及不同测量方法。 |
| 静脉血栓栓塞后管理 | 保存确诊、关键报告和既定随访计划。 | 展开 DVT/PE 类型、部位、日期、首次或复发、确诊影像及诱因；增加抗凝开始/中断、疗程复评、漏服、出血和持续症状。D-dimer 和残余血栓超声不作为全体患者决定停药的必查项。 |
| 风湿性心脏病 | 列入扩展目录，保存确诊、报告和计划。 | 增加风湿热及复发史、瓣膜受累及相关事件；保存医生开立的二级预防方案、实际给药、漏用、过敏和不良反应。与瓣膜病共用相应检查记录。 |
| 肥厚型心肌病 | 保存已确认病名、专科影像、心律或遗传资料、团队及计划。 | 展开最大壁厚及节段、LVEF、不同条件下的左室流出道压差、CMR 的晚期钆增强和心尖室壁瘤；补充晕厥、心律失常、家族史、遗传分类及 ICD 事件。静息和诱发压差分别保存。 |
| 致心律失常性心肌病 | 保存确诊及专科影像、心律、遗传资料，未展开具体字段。 | 增加左右室受累表型、射血分数、容积及体型校正、局部运动和纤维化；保存室早负荷、室速、运动暴露、遗传及 ICD 事件。不同表型分别记录。 |
| 肺动脉高压 | 保存确诊、专科报告、团队和随访计划。 | 展开右心导管的平均肺动脉压、楔压、肺血管阻力、心输出量、心脏指数和右房压，并记录方法；增加 WHO 功能分级、步行距离、BNP/NT-proBNP 和右心资料。超声估测与导管结果分开。 |
| 遗传性长 QT 综合征 | 保存确诊、相关心律或遗传资料及随访计划。 | 将 QT、QTc、校正公式、同步心率或 RR 间期及日期分别保存；增加运动/恢复期结果、事件诱因、家族史、相关药物和电解质背景。遗传性与获得性状态分开。 |
| Brugada 综合征 | 保存确诊、专科心电或遗传报告和计划。 | 展开 ECG 图形、导联位置、是否发热及自发/激发情境；补充症状、家族史、激发试验临床判读和确认的 ICD 事件。图形记录与确诊状态分开。 |
| 家族性胸主动脉瘤 | 保存确诊、影像、遗传资料、团队和随访计划。 | 增加受累亲属关系、病变部位、发病年龄和家族影像计划；细化基因、变异、转录本、合子状态、致病性分类及报告日期。意义未明变异不自动解释为病因。 |

## 共享数据与规则更新对照

| 内容 | 原来写了什么 | 更新后补充或细化了什么 |
| --- | --- | --- |
| 共享指标 | 血压、心率、体重、腰围、血糖、HbA1c、血脂、肾功能、生活方式和统一药单。 | 补充身高、可追溯计算的 BMI、血常规、电解质、尿检/UACR、肝功能、TSH 和铁代谢字段，按疾病及治疗需要读取，不设为全体必填。 |
| 指标拆分与单位 | 记录字段、单位和来源。 | 明确肌酐、eGFR、肌酐清除率分别保存；UACR、尿蛋白/肌酐比和尿常规蛋白分开；铁蛋白、血清铁、TSAT 分开；BNP 与 NT-proBNP 分开。换算保留原值、原单位和依据。 |
| 检查用途与状态 | 区分风险、异常待确认、确诊和事件；指出缺项。 | 明确初评、稳定期随访、症状变化评估、药物监测及术后随访；区分是否适用、开立、完成、待结果、阴性、未提供或原文冲突。缺失不自动等于正常或漏查。 |
| 证据与来源 | 有临床资料链接，输出可追溯。 | 区分指南支持、患者记录支持、病例支持和待补证；这些不构成证据分级，也不代表所有患者都适用。操作记录不能代替具体检查结果。 |
| 数据类型与历史 | 连续测量、症状、目标和治疗计划用于长期管理，数据由 App 保存。 | 区分诊断档案、重复测量及临床/治疗事件；新结果追加，旧结果保留；更正保留关系，失效记录不参与当前分析。 |
| 时间信息 | 记录日期与测量情境。 | 分开保存测量、文书、录入和事件时间；保留原时间精度。回顾历史时点时，不使用当时尚不可获得的后续资料。 |
| 趋势判断 | 汇总长期趋势，结合疾病背景解释。 | 先核对指标、标本、单位、方法及情境；输出观察窗口、有效记录数和跨度。两次结果可描述差异，“持续升高”等结论仍需专病规则支持。 |
| 目标与治疗变化 | 保存个人目标、处方和实际用药；关联症状与治疗。 | 目标与治疗方案保存来源、生效时间和历史版本；结果关联治疗调整及住院等事件。时间关联不自动解释为药物因果作用。 |
| 缺失与过时资料 | 资料不足时说明，不把缺检查当作正常。 | 显示最后结果日期、可用历史范围和缺口；没有新记录时不默认稳定。随访到期依据医生计划或已审核规则判断。 |
| 共病与提醒 | 同一测量共用，合并重复提醒，呈现潜在冲突。 | 提醒随新结果、计划变更和问题解决而更新；同一测量不重复计入趋势。各 Skill 保留判断依据，冲突交审核。 |
| App 调用与输出 | App 保存患者资料，Skill 保存通用知识；输出带依据、日期和版本。 | 调用时提供评估时点、新增或更正记录、相关历史、治疗事件和有效目标；返回可比趋势、当前状态、缺失和下一步提示。具体接口仍待实现。 |
| 测试 | 合成病例覆盖风险、确诊与多病共存。 | 增加连续病例序列，检查重复、乱序、日期缺失、单位/设备变化、长期缺测、目标变更、治疗调整、记录更正和提醒更新。 |

原有用药知识范围继续保留，覆盖降压、降脂、抗血小板、抗凝和心衰相关药物的类别与用途。实际处方与用药由 App 统一保存；复杂相互作用、抗凝选择及剂量调整需要医疗团队或经过验证的资料支持。急性风险仍进入统一安全流程，优先于常规趋势分析，不以先积累长期数据为前提。

正式 Skill 资料包仍需包含疾病名称与同义词、字段和单位字典、药物知识、经确认的教育材料、临床来源与版本、适用条件和合成测试病例。真实患者资料保存在患者档案，不写进通用 Skill 文件。

## 证据与实施状态

| 项目 | 当前状态 |
| --- | --- |
| 字段规划 | 已展开 18 类疾病，并补充共享字段、检查情境、来源及质量信息。 |
| 患者数据支持 | 依据原 50 人字段审计及[扩大检索报告](../cardiovascular-evidence-review/README.md)，逐病说明支持与缺口；不等于每病都有 50 名患者或所有新增字段都经过患者数据验证。 |
| 纵向验证 | 现有字段审计、补充数据和个案不能证明各病纵向管理有效。跨次就诊关联、有效时点、随访跨度及缺失情况仍需单独评估。 |
| App 实施 | 本表及共同纵向要求属于规划；尚未代表存储、调用、趋势分析或提醒已实现并验证。 |
| 临床规则 | 诊断阈值、个体目标设定规则、复查频率、药物剂量、风险评分自动计算和紧急提醒条件尚未形成可执行规则，启用前须绑定适用人群、排除条件、来源版本和临床审核。 |
| 跨团队分工 | 共享数据和提醒合并已有规划；与其他大类的具体维护归属仍需团队确认，聊天中的分工建议不视为已确认规则。 |

逐病临床引用和详细限制见[指标更新详文](cardiovascular-indicators-updated.md)；共同时间线、输入输出及验收要求见[纵向管理及 App 接入要求](longitudinal-app-requirements.md)。
