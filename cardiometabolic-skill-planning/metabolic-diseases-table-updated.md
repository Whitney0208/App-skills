# 代谢类慢性疾病 Skills：疾病与指标更新版

讨论稿，2026-09-30。本文件另存为[原中文汇报表](metabolic-diseases-table.md)的更新版，与[英文更新版](metabolic-diseases-table-en-updated.md)内容对应。原规划中的 17 类疾病或风险状态在这里分别列出，并结合本地 MIMIC-IV Note 病历核对及后续临床资料补充。原表保留。

本文件定义 App 需要能够接收和解释的数据。表内项目不代表功能已经实现、所有患者都必须接受同一组检查，或自动判断规则已经通过临床验证。确诊依据、常规监测和因症状追加的检查需要分开。检查选择取决于疾病、亚型、年龄、妊娠、治疗及临床情境。

## 纵向管理与 App 接入

代谢类与心血管类 Skill 共用[纵向管理及 App 接入要求](longitudinal-app-requirements.md)。每个疾病模块都要区分诊断档案、重复测量和带日期的临床或治疗事件。App 保存患者历史，并向 Skill 提供评估时点、相关测量、治疗变化和当时有效的个体目标。通用 Skill 文件保存知识与规则，患者历史由 App 管理。

解释趋势前需确认测量可比较、实际测量时间明确，并按已审核的专病规则检查观察窗口和资料是否充分。单次结果仅支持单时点解释，缺失或过时资料需要明确展示。输出保留所依据的记录、日期、规则版本、不确定性和随访状态。新结果追加到历史，不覆盖旧结果。目前的病历核对支持字段覆盖和来源追溯；跨次就诊的纵向行为仍需单独实现和验证。

## 证据与验证状态

| 证据层次 | 能说明什么 | 尚不能说明什么 |
| --- | --- | --- |
| 原规划字段 | 原英文摘要表或完整代谢病计划中已有的字段。 | 每名患者都具备这些记录，或 App 已经实现相应功能。 |
| 本地病历核对 | 能否从入组患者具有疾病依据的同次住院记录中检索预设词语和数值候选。逐病覆盖情况见[核对总结](metabolic-note-audit/SUMMARY.md)。 | 每项诊断已经独立确认、提到的检查已经完成、每个数值已得到正确医学解释，或疾病指标清单已经完整。 |
| 临床资料补充 | 由下方临床来源支持的新增候选字段。 | 这些字段已经通过本地患者样本验证；其中部分超出了原来的 50 字段检索词典。 |
| 拟定的 App 规则 | 如何保存依据、区分状态、展示缺项或趋势。 | 已获临床批准的诊断阈值、监测频率、药物剂量或自主调整治疗的规则。 |

本地核对检查的是预设字段的记录覆盖情况，尚未对病历中的所有信息进行开放式分析，以寻找全部可能遗漏的生物标志物。字段被检索过，不代表找到了符合条件的结果。叙述性提及、数值候选、计划检查、阴性陈述和比较阈值需要分别记录。

## 各疾病的具体指标

下表整合原规划与临床资料补充。遗传或酶学确诊报告通常属于诊断档案，列入表格不意味着每次随访都需要重复检测。按病情追加的检查在对应单元格中注明。

| 疾病或风险状态 | 核心测量与确诊依据 | 随访、并发症及按需补充 |
| --- | --- | --- |
| **2 型糖尿病** | 实验室空腹血浆血糖、HbA1c；需要确诊或澄清结果时的口服葡萄糖耐量试验（OGTT）；家庭血糖及进餐、设备情境。使用连续血糖监测（CGM）时，保存范围内时间（TIR）、低于范围时间（TBR）、高于范围时间（TAR）、平均血糖和波动情况。 | 低血糖事件及是否需要他人帮助；尿白蛋白/肌酐比（UACR）、肌酐、eGFR；眼底检查结果及已知视网膜病变；足部感觉、足部动脉搏动、神经病变和足溃疡。根据二甲双胍使用及临床表现评估维生素 B12。家庭血糖或 CGM 不能单独用于确诊。[ADA 综合评估](https://doi.org/10.2337/dc26-S004)、[血糖监测](https://doi.org/10.2337/dc26-s006)、[诊断](https://diabetesjournals.org/care/article/49/Supplement_1/S27/163926/2-Diagnosis-and-Classification-of-Diabetes)。 |
| **肥胖** | 身高、连续体重、BMI、腰围或腰高比；体重变化量、变化比例及时间范围。有临床需要或已有身体组成结果时，保存结果与测量方法。 | 血压、血糖和血脂结果、相关肝病资料、睡眠呼吸暂停症状、活动和关节功能受限、饮食、活动及体重相关治疗。身体组成影像并非所有患者的必查项目。[NICE 评估指南](https://www.nice.org.uk/guidance/ng246/chapter/Identifying-and-assessing-overweight-obesity-and-central-adiposity)。 |
| **血脂异常** | LDL-C、HDL-C、甘油三酯、总胆固醇、非 HDL-C、脂蛋白(a)；按风险评估需要保存载脂蛋白 B。记录 LDL-C 是直接测量值还是计算值。 | 既往心血管事件和家族史；治疗前后血脂趋势；处方治疗和耐受情况；按需要评估继发原因。保存采样条件和治疗背景。[2026 ACC/AHA 指南资料](https://www.acc.org/About-ACC/Press-Releases/2026/03/13/18/01/ACCAHA-Issue-UpDated-Guideline-for-Managing-Lipids-Cholesterol)。 |
| **糖尿病前期** | 实验室 HbA1c、空腹血浆血糖或 OGTT 的 2 小时血糖；复查结果及支持风险状态的依据。 | 体重、BMI、腰围、血压、血脂；糖尿病家族史、既往妊娠糖尿病及相关用药。保留风险状态是否持续、改善，或之后出现临床确认的糖尿病诊断。后续病历中的诊断文字本身不能证明疾病发生了生物学进展。[ADA 诊断与分型](https://diabetesjournals.org/care/article/49/Supplement_1/S27/163926/2-Diagnosis-and-Classification-of-Diabetes)。 |
| **代谢综合征** | 腰围、甘油三酯、HDL-C、血压、空腹血糖；会影响这些组成项的既有治疗。 | 保存采用的诊断标准、适用人群，以及每个组成项的日期和依据。不拼接不可比较的测量结果，也不凭缺项资料作出完整诊断。[NHLBI 诊断说明](https://www.nhlbi.nih.gov/health/metabolic-syndrome/diagnosis)。 |
| **MASLD（代谢功能障碍相关脂肪性肝病）** | 已有诊断及肝脂肪变性依据；ALT、AST、血小板；已有 FIB-4 结果及输入，包括年龄与测量日期；肝弹性成像/肝硬度及按需进行的其他纤维化检测。 | 心血管代谢风险因素、饮酒情况及其他肝病原因；医生提供的纤维化分期。进展期肝病可能需要胆红素、白蛋白、INR 和专科监测。计算或解释 FIB-4 前需核对适用条件和完整输入。旧 NAFLD/NASH 名称单独保留，待临床重新评估。[EASL–EASD–EASO 指南](https://doi.org/10.1007/s00125-024-06196-3)。 |
| **1 型糖尿病** | HbA1c、家庭血糖、CGM 指标、胰岛素方案及给药记录。为明确分型而检查的胰岛自身抗体、C 肽及同步血糖，保存为分型依据。 | 低血糖事件和低血糖感知；相关疾病期间或疑似酮症时的血酮/尿酮及急诊检查资料；UACR、eGFR、眼底和足部随访；按情况进行甲状腺评估及乳糜泻检查。分型检查与常规监测分开。[ADA 分型](https://diabetesjournals.org/care/article/49/Supplement_1/S27/163926/2-Diagnosis-and-Classification-of-Diabetes)、[综合评估](https://doi.org/10.2337/dc26-S004)、[血糖风险](https://doi.org/10.2337/dc26-s006)。 |
| **家族性高胆固醇血症** | 未治疗时或既往最高 LDL-C、当前完整血脂；本人及亲属早发心血管病史和发病年龄；腱黄瘤及相关体征；可用的遗传报告。 | 治疗反应、已知动脉粥样硬化性疾病、亲属评估及高 LDL-C 的继发原因。一般家族史文字不能直接确认为亲属早发心血管病。分子检测结果与临床诊断分别保存。[GeneReviews](https://www.ncbi.nlm.nih.gov/books/NBK174884/?report=reader)。 |
| **严重高甘油三酯血症** | 空腹甘油三酯及复查趋势；完整血脂；血糖/HbA1c；胰腺炎病史及支持严重程度的依据。 | 饮酒、饮食、用药、肾病及其他继发原因。疑似急性胰腺炎时，保存临床获得的化验和影像结果。疑似遗传性亚型时可能需要专科检查。未注明严重程度的病名不能自动归为严重型。[ACC 共识](https://www.acc.org/Latest-in-Cardiology/ten-points-to-remember/2021/07/27/21/04/2021-ACC-ECDP-Hypertriglyceridemia)。 |
| **痛风** | 血尿酸及连续趋势；发作频次、日期、关节部位、持续时间及疼痛；痛风石位置和变化。为澄清诊断进行的关节液晶体检查或影像，保存其原始结果。 | 肌酐、eGFR、肾结石史、处方降尿酸治疗、依从性、不良反应及治疗相关监测。尿酸结果需要结合临床病史解释。[NICE 痛风指南](https://www.nice.org.uk/guidance/ng219/chapter/Recommendations)。 |
| **苯丙酮尿症／PAH 缺乏症** | 血苯丙氨酸（Phe）、酪氨酸（Tyr）、已有 PAH 遗传报告及专科诊断解释；饮食中的蛋白质/Phe 摄入、处方医学营养及治疗。 | 生长、体重、营养状态；根据年龄和风险进行营养相关检验，例如按需检查血常规、铁蛋白或维生素 B12；认知、注意力、情绪、日常功能及妊娠/备孕状态。[GeneReviews](https://www.ncbi.nlm.nih.gov/books/NBK1504/?report=classic)。 |
| **糖原贮积病** | 先记录亚型及已有分子/酶学诊断。肝型按亚型关注血糖、低血糖、乳酸、酮体、甘油三酯、尿酸和肝功能；肌型按亚型关注肌酸激酶（CK）、肌力和运动耐力。 | 按亚型接入肝脏大小及结节影像、肾功能和尿蛋白、心电图及超声心动图。Pompe 病等相关肌肉表型可能需要呼吸功能、呼吸肌及吞咽评估。所有亚型不能共用一套检查方案。[Ⅰ型](https://www.ncbi.nlm.nih.gov/sites/books/NBK1312/)、[Ⅲ型](https://www.ncbi.nlm.nih.gov/books/NBK26372/)、[Pompe 病](https://www.ncbi.nlm.nih.gov/books/NBK1261/?report=reader)。 |
| **尿素循环障碍** | 血氨；血浆氨基酸谱中与亚型有关的谷氨酰胺、瓜氨酸、精氨酸等结果；需要分型时的尿乳清酸；已有遗传报告。 | 高氨事件和诱因、神经认知状态、蛋白质/能量摄入、营养和生长；按临床需要保存肝功能、凝血、电解质及血气。保留标本处理和采样情境。本次本地核对未获得符合入组条件的该病患者。[GeneReviews](https://www.ncbi.nlm.nih.gov/sites/books/NBK1217/)。 |
| **戈谢病** | 确诊资料：葡萄糖脑苷脂酶活性和 GBA1 结果。监测资料：血红蛋白、血小板、肝脾体积、肝酶，以及可获得的专科 Lyso-Gb1 结果。 | 骨痛、骨危象、骨折和骨坏死；有指征时的骨 MRI 或骨密度；出血、疲劳；按亚型评估神经和肺部受累；酶替代或底物减少治疗记录。本次本地核对尚未系统提取这些新增器官指标和生物标志物。[确诊](https://www.ncbi.nlm.nih.gov/books/NBK1269/)、[随访](https://www.ncbi.nlm.nih.gov/books/NBK1269/table/gaucher.T.gaucher_disease_recommended_su/)。 |
| **法布里病** | 确诊资料：α-半乳糖苷酶 A 活性、GLA 结果及专科 Lyso-Gb3 结果。肾脏资料：肌酐、eGFR、尿白蛋白/尿蛋白。 | 心电图、超声心动图及按需心脏 MRI；神经病理性疼痛、卒中/短暂性脑缺血发作（TIA）、听力及胃肠表现。女性不能仅凭酶活性正常排除疾病。器官评估依专科方案进行。[GeneReviews](https://www.ncbi.nlm.nih.gov/books/NBK1292/?report=reader)。 |
| **威尔逊病** | 铜蓝蛋白、血铜、24 小时尿铜分别保存，保留治疗和采样背景；已有 ATP7B 结果、裂隙灯/Kayser–Fleischer 环资料，以及按需进行的其他专科诊断检查。 | ALT、AST、胆红素、白蛋白、INR、血常规；神经和精神表现；根据治疗进行肾功能、尿检及不良反应监测。不同铜检测项目不能合并成一个未注明种类的临床数值。[GeneReviews](https://www.ncbi.nlm.nih.gov/sites/books/NBK1512/?report=reader)。 |
| **部分线粒体疾病** | 明确综合征/亚型及线粒体或核基因报告；诊断或相关临床情境中的乳酸，有指征时加丙酮酸或血气；CK、肌力和运动耐力。 | 按受累器官接入心电图/超声心动图、血糖/HbA1c、肾肝功能、听力、视力、神经认知、营养、吞咽和呼吸评估。乳酸不能单独确诊，也不能衡量所有亚型的病情严重程度。[Mitochondrial Medicine Society 共识](https://pmc.ncbi.nlm.nih.gov/articles/PMC7804217/)。 |

## 共享患者资料

共享字段只保存一次，并关联所有相关疾病 Skills。列入此表不代表每位患者都必须接受全部化验。

| 共享资料类别 | 需要保存的内容 |
| --- | --- |
| 人群与适用性 | 年龄、临床相关的性别信息、妊娠/备孕状态、已确认疾病及亚型、诊断日期、相关家族史。 |
| 身体测量 | 身高、体重、BMI、腰围、血压、心率及带时间的变化趋势。实测值与计算值分别标记。 |
| 检验结果 | 已有血糖/HbA1c、各项血脂、肌酐/eGFR、尿白蛋白/尿蛋白；按疾病和治疗需要保存肝功能、血常规、电解质。 |
| 生活与营养 | 饮食、饮酒、吸烟、活动、睡眠、进食困难及处方疾病相关营养方案。 |
| 治疗与实际使用 | 药名、剂量、频次、适应证、开始/停止日期、实际使用、漏用和患者报告的不良反应。一项药物可关联多个疾病。 |
| 症状与功能 | 出现时间、频次、严重程度及相关诱因；活动、认知、日常功能和照护者协助情况。 |
| 检查与随访状态 | 已完成、已安排、待结果或未提供；检查发现、负责团队、个体目标和既定随访计划。 |
| 结果来源 | 原始项目名称、数值、单位、标本、测量日期/时间、机构/设备、报告提供的参考范围，以及空腹、进餐和治疗情境。文书日期不自动作为测量日期。 |
| 诊断依据 | 医生确认、疑似、实验室风险状态或自述病史；本人患病与家族/携带状态分开；原始病名、亚型冲突及后续临床澄清结果。 |

## 本地核对的覆盖情况与限制

不足目标的人数是指定文字筛选规则下的结果，不证明数据库中没有其他患病者。诊断段落之外的全文关键词命中另存于本地供审核，其中包含鉴别诊断、家族史、检查目的和缩写撞词。没有提取到某字段，不能解释为结果正常、未做检查，或应删除临床上适当的指标。

本轮尚未系统提取所有测量日期、空腹/进餐状态、设备细节、药物剂量、依从性、人群适用性，或本文件新增的专科字段。尤其是年龄和妊娠适用性，未与结构化人口学表独立核对。住院文书也不能完整代表长期门诊或家庭监测情况。

## Skill 行为与临床审核

| Skill 功能 | 拟定行为及边界 |
| --- | --- |
| 初步风险评估 | 读取相关风险因素、症状和可靠检验。区分资料不足、值得讨论筛查、实验室风险状态和已确诊疾病。不仅凭 AD、PD、癌症或其他诊断推断糖尿病。 |
| 长期管理 | 对照医生给出的个体目标总结趋势，保存治疗与症状史，并识别既定随访计划中的缺项。 |
| 用药知识 | 支持处方核对、适应证、实际用药记录和患者报告的不良反应。独立调整剂量或处理复杂相互作用，需要本字段目录之外经过验证的临床支持。 |
| 多病共存 | 复用测量记录、合并重复提醒，并把冲突提交临床审核。保留每项解释所针对的疾病和依据。 |
| 急性风险 | 将相关急性发现交由 App 的统一安全流程处理。不根据本次样本直接推导预警阈值。 |
| 规则定义 | 启用前明确来源与版本、适用人群及亚型、必要输入、排除条件、缺失资料处理、临床审核状态和测试案例。本表不规定诊断阈值或随访频率。 |
| 正式 Skill 资料包 | 保存疾病定义及同义词、输入/单位字典、用药知识、已审核的患者教育材料、来源版本、解释与输出规则，以及合成测试案例。真实病历保存在患者数据中，不写入通用 Skill 指令。 |

本更新版仍是规划文档。后续开发中，扩展指标目录、功能实施状态、本地提取覆盖情况和临床审核状态需要分别维护。
