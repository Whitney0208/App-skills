# 代谢类慢性疾病 Skill：Lab 汇报表

讨论稿，2026-09-23。根据[代谢类疾病完整规划](metabolic-diseases.md)整理；下表是拟建范围，不代表 app 已实现。

## 目标与适用人群

| 问题 | 当前规划 |
| --- | --- |
| 服务谁 | App 中所有患者，包括已有 AD、PD、癌症、其他疾病，或尚无慢病诊断的人；不以某个现有疾病标签作为启动条件。 |
| 做什么 | 有相关资料时提示代谢风险；已有临床确诊时支持长期管理；资料不足时说明缺什么。 |
| 状态如何区分 | 筛查线索、检查结果处于风险范围、临床确诊分别记录；缺少检查不等于检查正常。 |
| 首版完整支持 | 成人 2 型糖尿病、肥胖、血脂异常。 |
| 首版有限支持 | 糖尿病前期与代谢综合征进入风险和预防路径；MASLD 先记录确诊、报告及随访缺项。 |

## 疾病与特有指标

| 疾病或状态 | 阶段 | 需要重点收集的特有指标与资料 | 管理重点或边界 |
| --- | --- | --- | --- |
| 2 型糖尿病 | 首版完整 | 实验室空腹血浆血糖、HbA1c、口服葡萄糖耐量试验；带测量情境的家庭血糖或 CGM；UACR、eGFR、眼底、足部和神经病变资料。 | 跟踪血糖与并发症随访；家庭血糖和 CGM 不单独用于确诊。 |
| 肥胖 | 首版完整 | 身高、连续体重、BMI、腰围或腰高比、变化时间；可用时记录身体组成测量方法。 | 结合个人目标、治疗方案及已确认的相关并发症；BMI 仅是筛查信息。 |
| 血脂异常 | 首版完整 | LDL-C、HDL-C、甘油三酯、总胆固醇、非 HDL-C；可用时记录脂蛋白(a)与载脂蛋白 B。 | 跟踪血脂趋势与已开立的治疗，不根据单个指标自动给出处方。 |
| 糖尿病前期 | 风险与预防 | 实验室 HbA1c、空腹血浆血糖或口服葡萄糖耐量试验。 | 保留构成依据，不写成 2 型糖尿病确诊。 |
| 代谢综合征 | 风险与预防 | 腰围、甘油三酯、HDL-C、血压、空腹血糖，以及影响这些结果的既有治疗。 | 明示满足与缺失的组成指标，不凭不完整资料确诊。 |
| MASLD | 首版有限 | 已有诊断、肝脏影像或弹性成像报告、ALT、AST、血小板、医生给出的纤维化分层与复查计划。 | 先记录与提示随访缺项；完整肝病规则需跨团队协调。 |
| 1 型糖尿病、家族性高胆固醇血症、严重高甘油三酯血症、痛风 | 扩展目录 | 分别关注胰岛素与急性风险、早发心血管病家族史及既往极高 LDL-C、胰腺炎史、专病治疗资料。 | 各病独立建规则；1 型不能套用 2 型规则，痛风边界需与风湿病负责人确认。 |
| 苯丙酮尿症、糖原贮积病、尿素循环障碍、戈谢病、法布里病、威尔逊病及部分线粒体疾病 | 罕见病目录 | 临床已确认的病名、原始报告、治疗团队、随访计划；专病资料可涉及苯丙氨酸、氨、乳酸、铜代谢、酶活性或基因检测。 | 首版仅识别和保存，不套用常见代谢病自动分析。 |

## 共享数据与 Skill 规则

| 模块 | 应收集或执行的内容 | 输出边界 |
| --- | --- | --- |
| 患者共享数据 | 基本资料、体重、腰围、血压、心率、血糖、HbA1c、血脂、肾功能、吸烟状态、饮食、活动、睡眠、实际处方和服药记录。 | 在患者档案中只保存一次；每条结果带日期、单位、来源和必要的测量情境，供各疾病 Skill 分别解释。 |
| 基础筛查 | 读取已知风险因素、症状及可靠化验，区分资料不足、值得讨论筛查、已有风险范围结果和临床确诊。 | AD、PD 或癌症标签本身不触发“疑似糖尿病”；提示必须给出具体依据，不将家庭血糖或 CGM 作为确诊依据。 |
| 长期管理 | 对已确认的疾病，读取个人目标、连续测量、治疗方案、症状、复诊和并发症检查。 | 生成趋势、数据缺口、既定随访提醒与患者教育；不自行改变处方或剂量。 |
| 用药知识 | 收录药物类别、适应证、处方核对、服药记录与患者报告的不良反应。 | 一项药可关联多个疾病；复杂相互作用与治疗调整交医疗团队或验证过的专用资料。 |
| 多病共存与安全 | 与心血管及其他模块共用原始数据，合并重复提醒，标出潜在冲突。 | 急性风险交 app 统一安全流程；每条输出可追溯数据日期、适用疾病、规则版本与缺失资料。 |
| 正式 Skill 资料包 | 病名与同义词、字段和单位字典、药物知识、经确认的教育材料、指南版本、适用条件、合成测试病例。 | 患者真实化验、处方和病历只留在患者档案；规则启用前由临床负责人确认。 |

依据与详细来源见[代谢类疾病完整规划](metabolic-diseases.md)。
