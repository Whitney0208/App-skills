# 心血管类慢性疾病 Skill：Lab 汇报表

讨论稿，2026-09-23。根据[心血管类疾病完整规划](cardiovascular-diseases.md)整理；下表是拟建范围，不代表 app 已实现。

## 目标与适用人群

| 问题 | 当前规划 |
| --- | --- |
| 服务谁 | App 中所有患者，包括已有 AD、PD、癌症、其他疾病，或尚无慢病诊断的人；不以某个现有疾病标签作为启动条件。 |
| 做什么 | 有相关资料时评估心血管风险与随访缺项；临床确诊后进入对应疾病的长期管理。 |
| 状态如何区分 | 风险因素、尚待确认的异常检查、确诊疾病及既往急性事件分开记录。 |
| 首版完整支持 | 成人高血压、慢性冠心病、心力衰竭、房颤。 |
| 跨病种边界 | 高血压既是管理对象，也是其他心血管病的风险因素；心梗和卒中后的长期预防纳入随访，卒中后的神经功能管理需与神经疾病负责人分工。 |

## 疾病与特有指标

| 疾病或状态 | 阶段 | 需要重点收集的特有指标与资料 | 管理重点或边界 |
| --- | --- | --- | --- |
| 高血压 | 首版完整 | 成对的收缩压/舒张压、时间、家庭或诊室来源、设备和测量情境；医生确认的个人目标。 | 看重复测量与长期趋势；一次家用读数不用于直接确诊或调整治疗。 |
| 慢性冠心病 | 首版完整 | 已确认的冠脉诊断、胸部不适及其变化、心梗或支架/搭桥史、运动耐量、心电图、功能检查与冠脉影像。 | 跟踪症状和二级预防；已开立药物注明适应证，不由 Skill 推断个人应服药物。 |
| 心力衰竭 | 首版完整 | 已确认的类型、超声左室射血分数（LVEF）；连续体重、气促、端坐呼吸、夜间憋醒、水肿、疲劳和活动能力；可用时记录 BNP/NT-proBNP。 | 结合症状、肾功能、电解质和用药整理变化；不凭体重变化单独推断液体潴留或改药。 |
| 房颤 | 首版完整 | 心电图或医疗记录确认的诊断、发作状态、心率、症状、卒中/TIA 史、医生评估的血栓与出血风险、抗凝处方。 | 跟踪漏服、出血报告、肾功能与复诊；穿戴设备提示仅作为待确认线索。 |
| 外周动脉疾病、脑血管病、瓣膜病、其他心律失常、主动脉瘤、成人先天性心脏病、静脉血栓栓塞后管理、风湿性心脏病 | 扩展目录 | 视病种保存 ABI、足部伤口、事件日期、超声瓣膜分级、主动脉影像直径、节律资料等原始报告。 | 首版先记录已确认诊断和既定随访；逐病建立专用规则。 |
| 肥厚型心肌病、致心律失常性心肌病、肺动脉高压、遗传性长 QT 综合征、Brugada 综合征、家族性胸主动脉瘤 | 较少见或罕见病目录 | 已确认病名、专科报告、相关影像/节律或遗传资料、治疗团队和随访计划。 | 首版只保存与展示，不套用通用高血压或心衰规则判断病情。 |

## 共享数据与 Skill 规则

| 模块 | 应收集或执行的内容 | 输出边界 |
| --- | --- | --- |
| 患者共享数据 | 血压、心率、体重、腰围、血糖、HbA1c、血脂、肾功能、吸烟状态、活动、睡眠和实际用药。 | 在患者档案中只保存一次；各 Skill 按疾病背景、症状和测量时间分别解释。 |
| 基础评估 | 面向所有有相关资料的患者，读取风险因素和可靠测量，指出检查或随访缺项。 | 单项症状、一次测量或穿戴设备提示不自动生成冠心病、心衰或房颤诊断。 |
| 长期管理 | 对已确诊疾病汇总趋势、症状、个人目标、治疗、用药和复诊计划。 | 生成患者、照护者及医生可核对的摘要；只按已确认的事件与诊断启用专病管理。 |
| 用药知识 | 覆盖降压药、降脂药、抗血小板药、抗凝药及心衰相关药物的类别与用途。 | 一项药物在统一药单中只显示一次；复杂相互作用、抗凝选择及剂量调整须经医疗团队或验证过的资料支持。 |
| 多病共存与急性安全 | 与代谢及其他模块共用数据，合并重复提醒，标出潜在冲突。 | 胸痛、突发神经症状、晕厥或明显呼吸困难进入统一安全流程，优先于常规趋势分析。 |
| 正式 Skill 资料包 | 病名与同义词、字段和单位字典、药物知识、经确认的教育材料、指南版本、适用条件、合成测试病例。 | 输出标注依据、日期、疾病状态、规则版本和缺失资料；患者真实测量、处方、心电图和影像只留在患者档案。 |

依据与详细来源见[心血管类疾病完整规划](cardiovascular-diseases.md)。
