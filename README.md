# App Skills

本仓库保存慢性代谢疾病与心血管疾病的 Skill 规划，以及用于核对字段的证据摘要。规划面向符合条件的所有患者，支持多病共存，不以 AD 或其他特定基础疾病为前提。

代谢类资料包含[疾病与能力范围](cardiometabolic-skill-planning/metabolic-diseases.md)、[中文汇报表格](cardiometabolic-skill-planning/metabolic-diseases-table.md)和[英文汇报表格](cardiometabolic-skill-planning/metabolic-diseases-table-en.md)。心血管类资料包含[疾病与能力范围](cardiometabolic-skill-planning/cardiovascular-diseases.md)、[中文汇报表格](cardiometabolic-skill-planning/cardiovascular-diseases-table.md)和[英文汇报表格](cardiometabolic-skill-planning/cardiovascular-diseases-table-en.md)。

2026-09-28 新增[心血管指标证据核对与扩大检索报告](cardiovascular-evidence-review/README.md)，说明原 50 人审计、新增 73 人检查数据及七类补充病例的证据范围、字段发现和局限。各来源分别统计，找到记录不代表诊断阈值或长期管理规则已通过验证。

同日新增[心血管指标更新版](cardiometabolic-skill-planning/cardiovascular-indicators-updated.md)，逐项展开 18 类疾病，补充共享化验、专病指标、检查场景及证据状态。原规划和中英文表格保留，便于比较。

仓库发布规划、证据摘要及公开来源链接。原始患者记录、逐人审计文件和全文下载缓存保留在本地。
