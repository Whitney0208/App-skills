# 心血管指标证据核对与扩大检索

检索与核对日期：2026-09-28。本轮围绕原规划未覆盖的七类疾病，并补查影像、遗传和血流动力学资料。原来的 MIMIC 50 人审计保持独立；这里增加一个已下载核对的真实患者数据来源、七篇成人病例的逐项提取，以及后续数据源目录。住院数据库、检查数据集和已发表病例具有不同证据范围，不能合并计算覆盖率或宣称临床有效性。

原始核对使用 [MIMIC-IV Demo v2.2](https://physionet.org/content/mimic-iv-demo/2.2/) 的 50 名不同成人患者，涉及规划中 11 类疾病的诊断编码。该样本用于尽量覆盖病种，不适合估计患病率；诊断编码也不等于独立临床复核。公开 Demo 缺少自由文本临床笔记，超声、影像和遗传结果存在明显缺口，因此开展本轮补缺。原始 50 人与新增来源分别统计。

已下载的 SCG-RHC 数据包含 73 个不同患者编号、83 次检查的 JSON 记录，其中 4 人的病史明确写有 HCM。七篇病例分别补充成人先天性心脏病、肥厚型心肌病、致心律失常性心肌病、肺动脉高压、遗传性长 QT 综合征、Brugada 综合征和家族性胸主动脉瘤。因此，18 类规划现在都有至少一个相关患者记录或已发表病例入口；这仅说明找到了资料，不能表述为“18 类疾病的所有指标已验证”。成人先心病仅以房间隔缺损为例，ACM 仅以 ARVC 为例，其他亚型仍需补充。

## 新增的患者级数据

[SCG-RHC v1.0.0](https://physionet.org/content/scg-rhc-wearable-database/1.0.0/) 是公开、去标识化的右心导管与可穿戴设备研究资料，来自心衰状态评估场景。本轮仅下载全部 83 份检查 JSON、记录清单、校验和与许可，没有下载大体积波形。全部 JSON 与发布方 SHA256 一致。以 TRM 编号去重得到 73 人；日期经过处理，不能用虚拟日期推算真实随访间隔。原 MIMIC 队列与本来源之间没有患者连接信息，不尝试跨来源识别或去重。

检查元数据中，平均肺动脉压 PAM、平均肺毛细血管楔压 PCWM、平均右房压 RAM、热稀释法心脏指数均在 83 次检查中有数值。Fick 法心输出量在 76 次检查、66 人中有数值；热稀释法心输出量在 82 次检查、72 人中有数值。NYHA 分级在 80 次检查中处于 I–IV 范围，按患者合并后 73 人至少有一次。官网描述的 NYHA 缺失人数与此提取结果不完全一致，需保留这个差异。以上是字段存在性检查，尚未核对波形质量或临床合理性。可复算统计、逐记录原值和下载校验清单保留在本地审计目录。

新数据中共有 4 人、5 次检查的病史明确记录 HCM。部分患者同时记录心衰、肺高压、高血压、房颤、冠心病及糖尿病。同一患者不同检查中的 HFpEF 与 HFrEF 标签应保留各自时点，不能拼成一个不变标签。这里缺少相应的完整超声、CMR 和遗传报告，无法独立复核 HCM 诊断；病史中的 pHTN 也不能直接升级为 PAH。

同一检查可以包含 Fick 法和热稀释法两种心输出量。app 应保留测量方法与原值，避免把方法不同的结果误判为录入冲突。

## 七类疾病的补充病例

成人先天性心脏病：一名 49 岁女性的房间隔缺损病例，同时有高血压、2 型糖尿病和高脂血症。检查提供缺损尺寸、分流比 Qp/Qs、肺血管阻力和术后肺动脉收缩压。超声 Qp/Qs 为 1.1–1.2，右心导管结果为 2.65，必须保留来源方法。不同视角和复查尺寸不适合直接解释为病变增长。原文术后文字与图注对残余缺损的描述有不一致，该结局标为待核对。[病例原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC13277483/)。

肥厚型心肌病：一名 67 岁女性同时有高血压、高脂血症和冠心病。超声室间隔舒张末期厚度 17.5 mm、LVEF >65%、LVOT 峰值压差 175 mmHg；导管检查在室性早搏后记录左室到主动脉压差 210 mmHg。字段应区分厚度测量部位和心动周期、压差方法与诱发条件。此病例未提供全面的纤维化、遗传或长期心律失常资料。[病例原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC6827703/)。

致心律失常性心肌病：一名 21 岁男性的 ARVC 病例记录 CMR 右室射血分数 39%、局部运动障碍、LGE 阴性、24 小时室早 >500 次，以及作者报告为致病的 PKP2 c.1689-1G>C 变异。后续有 ICD 终止室速的记录。可补充右室功能、室早记录时长、CMR 纤维化结果和装置事件字段；一项检查阴性不能替代整套专科评估。未独立复判论文的诊断标准计数。[病例原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC12450356/)。

肺动脉高压：一名成人女性的特发性 PAH 病例提供 WHO 功能分级、六分钟步行距离和多时点右心导管数据。2016 年血管反应性测试前，表 1 的 mPAP 为 48 mmHg、PAWP 为 12 mmHg、PVR 为 7.5 Wood units、心脏指数为 2.75 L/min/m²。原文在年龄、测试后 PVR 上存在不一致；作者对测试阳性的解释与表内心输出量下降也需专科复核。本轮采用明确标注时间的测试前数值，不把其治疗决策写成规则。[病例原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC9446687/)。

遗传性长 QT 综合征：病例系列的成人 Subject C 在诊断时 44 岁，最大 QTc 0.60 s，心率 56 次/分，有儿童期起反复晕厥及家族猝死史。作者报告 KCNH2 c.1834G>A（p.Val612Met）杂合、可能致病变异。需要记录 QTc 单位、校正公式、基因变异及其分类来源。该患者的校正公式没有明确给出，不能借用同篇另一患者的方法。[病例原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC12936859/)。

Brugada 综合征：一名 36 岁男性的病例记录变更胸前导联位置后的 1 型心电图、作者报告为致病的 SCN5A c.4222G>A（p.Gly1408Arg）变异和家族猝死史；2017 年药物激发试验曾为阴性。应分开保存心电图类型、导联位置、检查时间和诱发方式。原文明确说明其 ICD 植入决定超出所引用指南的常规适应证，不能据此生成普遍植入建议。[病例原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC10512029/)。

家族性胸主动脉瘤：一名 26 岁男性在首次夹层修复术后三个月，CTA 显示主动脉根部直径 5.3 cm，母亲有早发主动脉夹层史。作者报告当时所测基因均未检出变异。字段应包含解剖部位、直径、影像方法、手术与夹层史、受累亲属及发病年龄、基因检测范围。该病例依靠临床与家族资料归类；未获得分子确诊证据，也没有同部位连续直径可计算增长率。[病例原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC4109323/)。

七例的数值、单位、方法、时点、原文定位及质量问题已在本地结构化记录，全文缓存和文件哈希也保留在本地。上文链接指向公开原文，供读者复核。诊断与变异分类均标记为“作者报告”，没有通过图片自行测量或重新判定致病性；病例处方与剂量不转化为 app 用药建议。

## 扩大的数据来源目录

[ACDC](https://www.creatis.insa-lyon.fr/Challenge/acdc/databases.html) 是来自真实检查的心脏 MRI 数据集，共 150 人，其中 HCM 30 人。它适合继续核对心室容积、射血分数、心肌质量和壁厚等影像字段。官网提供数据入口，但本轮尚未下载原始影像或计算指标。其“右室异常”组不能自动等同于 ARVC，数据集分组条件也不能直接当作 app 临床诊断规则。

[EchoNet-Dynamic](https://echonet.github.io/dynamic/) 提供 10,030 段超声视频，以及 LVEF、收缩末期和舒张末期左室容积等标签。它能补充原 MIMIC Demo 缺少的影像数值，但不能据此断言拥有全部疾病亚型。个人需注册并遵守研究使用协议；本轮仅核对官方说明，未取得患者数据。其数据不能随意转存到公开 GitHub。

[THEW 的 Genotyped Long QT 数据库](https://thew-project.org/databases.htm) 列出 307 人、480 份 Holter 记录，可作为遗传性长 QT 的批量数据候选。已找到[学术注册入口](https://thew-project.org/register_SF.htm)，实际可申请范围和使用条件需按该通道核对。本轮未注册、付费或获取原数据，不把网站规模计入已审核人数。

[NHLBI 原发性肺高压登记库／BioLINCC 的 dbGaP 入口](https://www.ncbi.nlm.nih.gov/projects/gap/cgi-bin/study.cgi?study_id=phs004275.v1.p1) 提供病史、检查和生存随访资料的研究入口，需要授权访问。本轮仅检查登记说明，没有取得个体记录。其历史入组标准不能直接替代当前 PAH 定义。另找到 [PVDOMICS 的 TOPMed 登记入口](https://www.ncbi.nlm.nih.gov/projects/gap/cgi-bin/study.cgi?study_id=phs002451.v1.p1)，这里只作为肺血管疾病表型与遗传研究的候选，未据此声称获得完整临床字段。

## 对原 Skill 规划的具体影响

原文档对这七类主要保留“专科报告、影像、心律、遗传资料”的大范围描述。本轮把这些范围细化为可存储字段，并没有发现足够证据让全部字段变成每位患者的必查项目。个案只帮助检查“真实记录里有没有这种信息、原设计能否正确保存”，检查适应证、阈值和随访频率仍须逐项依据指南及专科审核。

最需要补充的是数值背后的条件：测量部位与方法、静息或诱发状态、检查相对治疗的时间、记录时长、基因转录本与变异分类日期。疾病状态、历史诊断、当前检查发现也要分开。数据不足、结果阴性和没有进行检查，应保存为不同状态。

多病共存的例子已经来自实际资料，支持统一保存共享指标与药单、按疾病解释用途的设计。下一轮审计应优先把这些字段映射回规划，标注“已有记录支持”“需要指南补充”“原文冲突待核对”和“本轮仍无证据”。此次 GitHub 更新发布核对摘要和来源链接。原始患者记录、逐人病史、全文下载缓存及患者级机器可读文件保留在本地；正式 Skill 和患者 app 未修改。

## 检索与复核范围

本轮使用 PubMed/PMC 与 Europe PMC 的原始病例全文、PhysioNet 原始数据，以及 ACDC、Stanford、THEW 和 NIH 的官方数据目录。检索将七个疾病英文名称分别与 case report、ECG、CMR、genetic、right heart catheterization、dataset 等词组合，依据 DOI 去重。属于定向补缺检索，没有声称系统综述或完整搜索全部数据库。

优先保留成人、有明确诊断叙述、具有患者级测量与可定位全文的来源。15 岁 ARVC 病例 PMC10858638 未进入成人补充组；药物相关 Brugada 图形、单纯肺高压编码、仅有右室异常的数据组，都不自动计入对应确诊类别。原文存在冲突时保留冲突，未用外推数值补齐。

本地已核对七篇 DOI、患者范围、所用数值与检查背景，并验证全部 83 份检查 JSON 与发布方 SHA256 一致。病例字段由逐项提取和复核得到，脚本不自动作临床判断。本报告对应原有[心血管 Skill 规划](../cardiometabolic-skill-planning/cardiovascular-diseases.md)，属于证据补充，不替代原规划或临床指南。
